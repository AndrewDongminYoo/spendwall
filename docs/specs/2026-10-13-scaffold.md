# Repository scaffold

## Contract

Implement [issue #1](https://github.com/AndrewDongminYoo/spendwall/issues/1) on the existing initial commit.
Provide a pnpm workspace, MIT license, reproducible checks, a staged-secret commit gate, and local Postgres.

## Scope

- TypeScript skeletons: `packages/policy`, `apps/firewall`, `apps/agent-demo`, and `apps/dashboard`.
- Reserve `apps/approver` for Flutter outside pnpm.
- Ignore private environment files and commit only the example template.
- Use Gitleaks to inspect staged content, including when the working copy differs.
- Run lint, strict type checking, security-hook tests, and Compose validation in CI.

## Acceptance

1. `pnpm install --frozen-lockfile` succeeds on Node 24 with the pinned pnpm version.
2. `pnpm lint`, `pnpm typecheck`, and `pnpm test` succeed locally and in GitHub Actions.
3. A synthetic staged credential prevents a real commit without printing the credential.
4. A clean commit succeeds, while a missing scanner fails closed.
5. Compose validates with only a Postgres service and a loopback host port.
6. GitHub detects MIT on the PR branch; default-branch About detection follows merge.

## Non-goals

No payment calls, credentials, policy implementation, NestJS service, React UI, or Flutter SDK initialization.
No merge or deployment is authorized by this task.

## Constraints

Preserve the existing pnpm version and initial commit.
Keep all packages private until publishing is explicitly required.
Trunk manages the repository's pre-commit and pre-push hooks.
Secret scanning reduces accidental disclosure; it does not guarantee detection of every secret format.
