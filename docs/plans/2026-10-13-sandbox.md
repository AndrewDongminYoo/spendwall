# Sandbox setup plan

## Ownership and direction

The root agent owns `docs/sandbox.md`, this plan, the sandbox spec, `scripts/check-paypal-sandbox.mjs`, and `tests/paypal-sandbox.test.mjs`.
This implements issue #2 under the approved milestone workflow.
No visual approval is applicable to this command and setup guide.

## Steps

1. Document setup from PayPal's authentication, sandbox-account, and advanced-card integration guides.
2. Write token-check tests and observe the success contract fail against an unimplemented function.
3. Implement the fixed sandbox request with redacted output and a request deadline.
4. Run `node --test tests/paypal-sandbox.test.mjs`, then the repository checks.
5. Review the complete diff for secret disclosure, live-host access, and false readiness claims.
6. Run `node scripts/check-paypal-sandbox.mjs` with locally supplied sandbox credentials.
7. Commit and publish the scoped result through PR Loop; retain pending live acceptance if credentials are unavailable.

## Evidence boundaries

Injected HTTP responses test local behavior only.
A real successful token request is required for the issue's token criterion.
Account country and app feature eligibility require Dashboard confirmation.
