# Audit implementation plan

**Goal:** Implement and verify the isolated #11 Postgres audit boundary.

**Spec:** `docs/specs/2026-10-14-audit.md`.

**Architecture:** A firewall TypeScript module prepares safe events, calls a
Postgres append function, and verifies actual row payloads in a consistent
snapshot. A disposable Docker runner exercises the app role and owner separately.

**Constraints:** Node >=24.21.0 <25; pnpm 11.24.0; strict TypeScript;
frozen install, lint/typecheck/test/Trunk/Compose checks; no changes to policy;
no payment requests, production migrations, credentials, deployment or merging.

## Task 1: Safe event boundary

- [ ] Write `tests/audit.test.mjs`: canonical argument hashes, recursive removal
      of credentials/PII/free text, malformed input rejection and safe errors.
- [ ] Run `node --test tests/audit.test.mjs`; observe missing boundary failure.
- [ ] Implement `apps/firewall/src/audit/event.ts`: `prepareEvent(input)` returns
      validated JSON metadata, original args hash and safe argument/context JSON.
- [ ] Re-run the unit tests; require all passing.

## Task 2: Durable chain and verifier

- [ ] Add real Postgres tests for all decisions/event kinds, permission denial,
      40 concurrent appends, rollback and first/middle/last-row mutations.
- [ ] Run tests before the migration/module; observe missing append boundary.
- [ ] Implement `migrations/001-audit.sql` (owner migration),
      `apps/firewall/src/audit/index.ts` (`AuditLog.append`, `verifyAudit`) and
      `scripts/audit-verify.mjs` (read-only CLI, safe failure diagnostics).
- [ ] Add pinned `pg` and types, regenerate lockfile, verify frozen install.
- [ ] Add a temporary-container test runner to `pnpm test`, including existing CI.
- [ ] Run unit and real Postgres tests; require exact row identification and
      valid concurrent chain. Verify CLI behavior and empty/head corruption.

## Task 3: Review and delivery

- [ ] Document migration/role setup, redaction contract, future call-site
      interface, threat-model limits and local test instructions in `docs/audit.md`.
- [ ] Run all repository checks. Record blockers and actual evidence.
- [ ] Review the whole diff; fix important findings with regression tests.
- [ ] Commit with installed hooks; publish a normal PR, inspect bounded review
      feedback and exact-head CI. Do not merge or request paid reviews.

Review focus: sensitive metadata/free text; invalid JSON; forged/direct inserts;
concurrent snapshots; tail removal; secret-containing database errors.

Execution decisions: use this isolated cloud checkout and topic branch; implement
inline within the explicitly delegated scope. The cloud `.agents` directory is
empty and no `pr-loop` skill is installed; preserve the requested normal-PR and
bounded review-loop behavior manually and report this limitation.
